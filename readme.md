Color grid

You can move your mouse over the Color Grid to draw switch between coloring modes erase cells or change how big the Color Grid is.



Features

Normal Mode. Colors squares black

Color Mode...Gives each hovered square a RGB color

Grey Mode.... Gradually darkens squares as you hover over them repeatedly

Eraser Mode.... Changes colored squares back to white

Custom Grid Size. Choose between 1 × 1 and 100 × 100

Reset. Clears the grid while keeping the selected grid size



Technologies Used

HTML5. Project structure

CSS3. Layout and styling

JavaScript. Grid generation and interactions

DOM Manipulation. Dynamically creates and updates grid squares



Grid Size

The default grid is:

10 × 10

You can change the grid size from:

1 × 1

up, to:

100 × 100
